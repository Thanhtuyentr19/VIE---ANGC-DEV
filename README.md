## Chạy website

Không cần cài đặt thư viện hoặc framework. Mở trực tiếp `index.html` bằng trình duyệt.

Nếu muốn chạy bằng máy chủ cục bộ:

```powershell
python -m http.server 8080
```

Sau đó truy cập `http://127.0.0.1:8080`.
